- Mode rencana = hanya membaca + bertanya, tanpa mengubah file.
- Mode eksekusi = ubah file, verifikasi (`node --check`), commit + push.
- Setiap perubahan diverifikasi di light + dark dan HP sebelum dinyatakan selesai.
